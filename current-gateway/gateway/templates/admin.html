ACCESS


    

      Administration Boundaries
    


    

      

        
Student Access


        

          Students use supported experiment workflows from the designated
          CPS Studio teaching lab workstation.
        

      


      

        
Instructor Access


        

          Experiment supervision, recovery, and evidence access are provided
          through the authenticated CPS Studio Administration interface.
        

      


      

        
System Administration


        

          Raspberry Pi operating-system and service administration use
          separate SSH public-key authentication.
        

      


      

        
Device Communication


        

          The Raspberry Pi Gateway communicates with ESP32 devices over the
          private CPS Studio Wi-Fi network using device-specific authentication.
        

      

    


    

      These responsibilities remain separate so that student experiment access
      does not grant instructor, Raspberry Pi, or unrestricted device
      administration.
