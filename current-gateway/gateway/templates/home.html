GATEWAY

What the Gateway Does

The Sentinel Gateway connects CPS Devices to the Lab Workstation. It checks permitted operations, manages device communication, and keeps student access separate from system administration.

PHYSICAL COMPUTING

Built Around Real Hardware

CPS Studio uses real microcontrollers, sensors, and actuators in the IoT & Robotics Lab. Each CPS App provides a different way to experiment with the hardware.
